### shell

- zsh — shell, with [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions) and [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting)
- [starship](https://starship.rs) — prompt, with Nerd Font icons
- [mise](https://mise.jdx.dev) — runtime manager (`node`, `python`)
- [eza](https://github.com/eza-community/eza) — `ls`
- [fzf](https://github.com/junegunn/fzf) — fuzzy finder (`ctrl+r`, `ctrl+t`)
- [zoxide](https://github.com/ajeetdsouza/zoxide) — smarter `cd`

### terminal

- [kitty](https://sw.kovidgoyal.net/kitty/) — JetBrainsMono Nerd Font, TokyoNight Day/Night following the system appearance
- [tmux](https://github.com/tmux/tmux) — `ctrl+hjkl` panes, lazygit and scratch popups, TokyoNight status line
- `dev` — opens a project in a three-pane tmux session
