### shell

- [bash](https://www.gnu.org/software/bash/) — shell
- [starship](https://starship.rs) — prompt
- [mise](https://mise.jdx.dev) — runtime manager (`node`, `bun`, `python`)
- [eza](https://github.com/eza-community/eza) — `ls` with icons
- [bat](https://github.com/sharkdp/bat) — `cat` with syntax highlighting
- [fd](https://github.com/sharkdp/fd) — faster `find`
- [fzf](https://github.com/junegunn/fzf) — fuzzy finder
- [zoxide](https://github.com/ajeetdsouza/zoxide) — smarter `cd`
- [yay](https://github.com/Jguer/yay) — AUR helper (`up`, `pin`, `prm`, `pss`)
